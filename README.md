AI-помощник для анализа грантовых документов

Описание проекта

Интеллектуальный помощник на основе генеративного искусственного интеллекта, предназначенный для автоматизации анализа грантовой документации. Система извлекает структурированную информацию из документов, отвечает на вопросы пользователя и сокращает время обработки документов вдвое при точности >90%.

Проблема

Ручной анализ грантовых документов занимает 30–50 минут при норме 28 минут, что приводит к:

· Потере времени
· Повышению риска ошибок из-за рутинной работы

Решение

ИИ-помощник, который:

· Сокращает время анализа вдвое
· Обеспечивает точность ответов >90%
· Работает в формате вопрос-ответ
· Обрабатывает документы локально (без отправки данных на внешние серверы)

Техническая реализация

1. Создание датасета

· Источник данных: 184 PDF-документа с сайта Российского научного фонда (https://rscf.ru)
· Парсинг: автоматический сбор документов с помощью requests и BeautifulSoup
· Обработка: извлечение текста из PDF с использованием PyMuPDF
· Генерация QA-пар: создание 1450 тематических пар "вопрос-ответ" через YandexGPT API
· Бюджет: использовано 1172 руб. из гранта 4000 руб. в Yandex AI Studio

2. Выбор модели

· Базовая модель: Vikhrmodels/QVikhr-3-4B-Instruction
· Метод дообучения: QLoRA (эффективное адаптирование на доступном оборудовании)
· Преимущества: баланс между производительностью и требованиями к ресурсам

3. Архитектура системы

· Бэкенд: дообученная модель QVikhr-3-4B-Instruction
· Интерфейсы:
  · Telegram и MAX-ботs

· Принцип работы: пользователь загружает PDF, задаёт вопросы в чате, ИИ анализирует документ и даёт ответы с цитированием
