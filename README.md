grant_ai_assistant

Интеллектуальный помощник для анализа грантовой документации на основе генеративного искусственного интеллекта. Система позволяет в формате вопрос-ответ извлекать необходимую информацию из документов Российского научного фонда, сокращая время анализа вдвое при точности, эквивалентной 90%.

Проблема

Ручной анализ грантовых документов занимает от 30 до 50 минут при нормативе 28 минут (рассчитанном исходя из ежедневной загрузки проектного офиса). Это приводит к систематическим переработкам и повышенному риску ошибок из-за рутинного характера работы.

Решение

Разрабатываемый ИИ-помощник:

· принимает от пользователя PDF-документ и вопросы по нему;
· с помощью RAG-пайплайна находит релевантные фрагменты текста;
· на их основе генерирует точный ответ с возможностью цитирования источника.

Все вычисления выполняются локально, данные не передаются на внешние серверы – это обеспечивает полную конфиденциальность, что особенно важно для работы с документацией государственных заказчиков.

Техническая реализация

Датасет

· Собран корпус из 184 PDF-документов с официального сайта РНФ (парсинг с помощью requests и BeautifulSoup4).
· Извлечение и очистка текста выполнены с использованием PyMuPDF.
· С помощью YandexGPT API сгенерировано 1461 тематических пар «вопрос-ответ». Стоимость генерации составила 1172 рубля из гранта 4000 рублей в Yandex Cloud.
· Датасет разделён по документам на обучающую, валидационную и тестовую выборки (1022/216/223 пары), что исключает утечку контекста и позволяет объективно оценивать качество моделей.

RAG-ядро

· Тексты разбиты на чанки размером 700 символов с перекрытием 150 символов.
· Для построения векторных представлений используется модель intfloat/multilingual-e5-small, оптимизированная для русского языка.
· Векторная база данных ChromaDB содержит 32 067 чанков.
· Тестирование на 50 случайных вопросах из валидационной выборки показало:
  · 100% успешных поисков (релевантный фрагмент всегда входил в топ‑3);
  · среднее косинусное сходство найденных чанков с эталонными ответами – 0,84.

Генеративная модель

В качестве базовой выбрана модель QVikhr‑3‑4B‑Instruction – русскоязычная версия Qwen3‑4B, дообученная на инструкциях. Её преимущества:

· высокое качество русского языка (оценка 78.2 в рейтинге Ru Arena General);
· компактность: в 4‑битном формате GGUF занимает около 2,5 ГБ и может запускаться на CPU;
· совместимость с методом эффективного дообучения QLoRA.

Интерфейсы

Финальная архитектура предусматривает два варианта взаимодействия:

· Telegram‑бот – для широкого круга пользователей;
· бот в мессенджере MAX  

Связующим звеном выступает бэкенд на FastAPI, который управляет RAG-пайплайном и вызовом модели.

Ожидаемые результаты

· Точность ответов, эквивалентная 90% (подтверждаемая набором метрик: BERTScore ≥0.80, F1 на ключевых фактах ≥0.75, Faithfulness ≥80%).
· Сокращение времени анализа документа с 30–50 минут до менее чем 15 минут.
· Поддержка загрузки PDF и текстовых файлов.
· Полная локальность обработки данных.
