# grant_ai_assistant

Интеллектуальный помощник для анализа грантовой документации на основе генеративного ИИ (RAG + LLM). Система позволяет в формате «вопрос-ответ» извлекать информацию из документов Российского научного фонда, сокращая время анализа вдвое.

## 📌 Проблема
Ручной анализ грантовых документов занимает 30–50 минут (при нормативе 28 минут), что приводит к переработкам и риску ошибок.

## 🚀 Решение
ИИ-помощник:
- Принимает PDF/DOCX и вопросы по нему.
- Через RAG-пайплайн находит релевантные фрагменты.
- Генерирует точный ответ на основе контекста.
- **Все вычисления локальны**, данные не передаются вовне — полная конфиденциальность.

## 🧱 Архитектура

### Компоненты
- **Backend (FastAPI)** – управление сессиями, RAG, вызов LLM.
- **RAG-ядро** – чанкинг (700/150 символов), эмбеддинги (`intfloat/multilingual-e5-small`), векторный поиск (ChromaDB).
- **Генеративная модель** – `QVikhr-3-4B-Instruction`, дообученная QLoRA, квантизована в GGUF (Q4_K_M, 2.38 ГБ).
- **Интерфейсы** – Telegram-бот (локальный или на сервере), планируется бот для MAX.

### Датасет
- 184 PDF-документа с сайта РНФ.
- 1461 синтетическая пара «вопрос-ответ» (YandexGPT).
- Разделение по документам на train/val/test (1022/216/223).

### Оценка
- **RAG**: точность поиска 95%, косинусное сходство 0.84.
- **Fine-tuned модель + RAG** (на тестовой выборке):
  - ROUGE-L: 0.46 (цель 0.50)
  - BERTScore F1: 0.87 (цель 0.80) ✅
  - F1 по фактам: 0.81 (цель 0.75) ✅
  - Faithfulness: 86% (оценка через YandexGPT) ✅
